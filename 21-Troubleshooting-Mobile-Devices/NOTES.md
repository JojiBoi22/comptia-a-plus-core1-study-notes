# Troubleshooting mobile devices (Objective 5.4)

Yellow tab: **Troubleshooting Mobile Devices**.

Topics: power, hardware, performance, display, connectivity, malware / infection.

## Power

If a laptop will not charge:

1. Confirm the AC adapter is seated and the brick LED (if it has one) is on.
2. Check the motherboard DC jack.
3. **Removable battery:** swap it.
4. **Non-removable battery:** send for repair / battery service — do not pry a glued pack unless you are trained.

Phones last longer if you avoid sitting at 100% or 0% all day. A common target window is about 20–80% for daily top-ups. A swollen pack is a fire risk — stop using it.

## Hardware

- Overheating (blocked vents, gaming on a pillow, dying thermal paste).
- Liquid damage.
- Broken ports (USB-C, Lightning, headphone, charge pin).

## Performance

Slow, or cannot install apps.

Usual causes:
- Not enough **RAM** (random access memory), storage, or CPU / GPU headroom.
- Old software.

Fixes: install operating-system updates, close background apps, free storage, factory reset only after backup.
